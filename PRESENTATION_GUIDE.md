- **Project Title**: Tutor Management System (TMS)

## 🏆 Key Talking Points for Faculty Questions

- **Why both 1-on-1 and Batch tutoring?** Independent tutors manage individual students alongside group batches; TMS unifies session participants, attendance, assignments, and messaging in a single relational schema.
- **Why double implementation of Design Patterns (Java + TS)?** Java is the classic object-oriented benchmark taught in CSE327, while TypeScript/Node runs the full-stack web application. Both codebase folders (`docs/java_patterns/` and `backend/patterns/`) mirror identical GoF pattern contracts.
